### Each of the pages in the site has a corresponding Markdown (.md) file where its content lives. These files can be edited directly in the Github Main branch, and committed, without concern for breaking the website.

#### Markdown Pages (under the /content directory):
- Home - index.md
- Our Story - bio.md
- Contact Me - contact.md
- Services - services.md
- styleguide.md (This is not linked from anywhere on your site, so nobody would know how to get here. Its just where I'm keeping design standards and guidelines (colors and stuff. accessible at sunsetpaws.pet/styleguide.html))

#### Below is how you'd make heading tags for the site:
# H1 Heading
## H2 Heading
### H3 Heading
#### H4 Heading 
##### H5 Heading
###### H6 Heading 

#### Bulleted Lists just begin with a dash
- Bullet List Item
- Bulleted List Item
- Bulleted List Item

#### Numbered Lists can start with any you want. Even if you use 1. for all of them, it will still render a numbered list in order. This is nice because you can move things around in the list and not worry about re-numbering them
1. Numbed List Item
1. Numbered List Item
1. Numbered List Item

#### How to create a link to another site or another page in your site
#### This is an example of using links in a list (just add the dash before the link)
- [Link to Google](https://www.google.com)
- [Link to Cloudflare](https://www.cloudflare.com)

In the examples above, the text in the [] brackets can be anything you want, and that is what the link will say on the site. Whats in the () parenthasis is just the URL that you want to link to
