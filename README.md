# Sunset Paws — Adaptive Pet Care

A static website for Sunset Paws pet care services, built with Vite and Handlebars, deployed on Cloudflare Workers.

## Prerequisites

- Node.js 22 (see `.node-version`)
- npm
- [Wrangler CLI](https://developers.cloudflare.com/workers/wrangler/) (for deployment)

## Getting Started

```sh
git clone git@github.com:brandyge/adaptive-pet-care.git
cd adaptive-pet-care
npm install
npm run dev
```

## Project Structure

```
content/          # Markdown content files (bio, services, contact, etc.)
pages/            # Handlebars HTML templates (one per page)
src/
  components/     # Handlebars partials and their CSS
  styles/         # Global styles
  main.js         # Client-side entry point
  worker.js       # Cloudflare Worker (API routes)
public/           # Static assets (images, fonts)
dist/             # Built output (generated by `npm run build`)
```

**Content flow:** Markdown in `content/` → converted to HTML via Marked → injected into Handlebars templates in `pages/` → built to `dist/`.

## Tooling

| Tool | Purpose | Commands |
|------|---------|----------|
| **Vite** | Dev server and build | `npm run dev`, `npm run build`, `npm run preview` |
| **Handlebars** | Templating via `vite-plugin-handlebars`; partials live in `src/components/` | — |
| **Marked** | Markdown → HTML conversion for content files | — |
| **Wrangler** | Cloudflare Workers CLI | `npm run cf:deploy` |

## Integrations

### Resend (Email)

The contact form submits to `POST /api/contact` (handled in `src/worker.js`), which sends email via [Resend](https://resend.com).

Requires the `RESEND_API_KEY` secret on Cloudflare:

```sh
npx wrangler secret put RESEND_API_KEY
```

## Hosting & Deployment

The site is hosted on **Cloudflare Workers** with static asset serving from `./dist`. Configuration is in `wrangler.jsonc`.

```sh
npm run build
npm run cf:deploy
```

## Environment Variables

| Variable | Description | How to set |
